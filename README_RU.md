# Starfall Nuke (Minecraft 1.20.1 Forge)

Полноценный мод на ядерный удар «падающей звездой» (как в *The Shooting Star*).

## Что доработано и добавлено
1. **Два режима запуска («Ядро Звездопада» — `starfallnuke:starfall_core`)**:
   - **ПКМ**: бросок ядерного ядра по направлению взгляда.
   - **Shift + ПКМ**: орбитальный вызов «Падающей звезды» с высоты неба в точку, куда ты смотришь (дальность до 120 блоков).
2. **Эффект ядерного удара**:
   - Основной взрыв силой `28.0F` + кольцо из 8 вторичных взрывов силой `14.0F` для широкого кратера.
   - Оплавление центра кратера (магма и обсидиан), ударная волна, поджог, слепота и иссушение в радиусе 45 блоков.
   - Грибовидное облако из частиц взрыва, пламени, звёздных искр и дыма + раскат грома.
3. **Вкладка креатива, текстура и локализация**:
   - Предмет добавлен во вкладки *Бой* и *Инструменты*.
   - Собственная пиксель-арт текстура `starfall_core.png` и логотип мода `logo.png`.
   - Подсказки на русском и английском языках.

## Как получить готовый `.jar`
### Способ 1 — Без установки программ (через GitHub за 2 минуты)
1. Создай бесплатный репозиторий на GitHub и залей туда файлы из архива (включая папку `.github`).
2. Открой вкладку **Actions** -> **Build StarfallNuke JAR** -> **Run workflow**.
3. Скачай готовый `starfallnuke-1.0.0.jar` из раздела **Artifacts** и закинь в папку `mods`.

### Способ 2 — На своём ПК
1. Установи **JDK 17** (Adoptium Temurin 17) и **Gradle 8.5**.
2. Запусти `build_mod.bat` (или команду `gradle build` в папке проекта).
3. Готовый файл появится в `build/libs/starfallnuke-1.0.0.jar`.

## Крафт и команда выдачи
- Рецепт: 4 обсидиана по углам, 4 динамита по сторонам, 1 звезда Незера в центре.
- Команда в игре: `/give @p starfallnuke:starfall_core`
